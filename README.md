# NEXUS NEON

Offline Android editor and isolated beginner script sandbox.

## Build APK
Open the **Actions** tab and run **Build NEXUS NEON APK**, or push a commit to `main`. When the workflow completes, download the `NEXUS-NEON-debug-apk` artifact.

## Safety and scope
This project is a local editor and limited educational test runner. It does not inject into Roblox, bypass platform protections, or execute code inside third-party games.
